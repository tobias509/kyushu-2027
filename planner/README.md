# 2027 九州家族行｜行程規劃網站

暗色鐵道風的行程規劃頁面，網址：https://tobias509.github.io/kyushu-2027/planner/

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `data.js` | 旅程資料（行程、住宿、備案、攜帶用品），要改行程就改這裡 |
| `app.js` | 行事曆、地圖、費用、用品等功能 |
| `illustrations.js` | 原創 SVG 插圖與每天的選圖規則 |
| `style.css` | 配色與版面 |

## 本機測試

```bash
cd kyushu-2027
python3 -m http.server 8765
# 開 http://localhost:8765/planner/
```

網址加上 `?now=2027-02-07T14:00` 可以測試「現在時間」紅線。

## 資料存放

- 在網頁上做的修改會存在這台裝置的瀏覽器（localStorage），換裝置或換瀏覽器就看不到。
- 要備份或搬到別台裝置，用右下工具選單的「匯出 JSON」和「匯入 JSON」。
- 「還原預設資料」會回到 `data.js` 的內容，按復原可以撤銷。

## 假設與待查

- 座標是估算值，地圖路線是直線示意，不是實際的道路線形。
- 由布院之森、機場巴士、別府巴士的時刻都是估算，要以購票或官網為準。
- 標示「估」的門票價格（地獄共通券、纜車、入湯手形、火山博物館、熊本城、水前寺、吊橋）都要再查官網。
- 匯率留空，請在「費用總覽」自己填。
- 別府、高千穗、熊本的住宿還沒訂，奥阿蘇のあかまつ的金額待填。
